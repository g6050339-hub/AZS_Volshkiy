# ⛽ Мониторинг АЗС Волжского — Telegram Bot & Mini App

Система 24/7 мониторинга наличия бензина на АЗС г. Волжский и других городов России.

## 🔥 Возможности

- **Telegram Bot** (`@AZS_Volzhkiy_bot`):
  - Проверка наличия топлива каждые 3 минуты
  - Push-уведомления о появлении/исчезновении топлива
  - Настройка подписок по маркам (АИ-92, 95, 95+, 100, ДТ)
  - Фильтрация АЗС по типу топлива

- **Telegram Mini App** (интерактивная карта):
  - Карта всех АЗС с цветовой индикацией наличия
  - Фильтры по маркам топлива (АИ-92, 95, 95+, 100, ДТ)
  - Карточки станций с ценами, очередями и навигацией
  - **Встроенный навигатор** с поиском заправок по пути (коридор 800м)
  - Экспорт маршрута в Яндекс.Навигатор
  - Автообновление данных каждые 60 секунд
  - Мультигородская поддержка (37 городов)

## 📁 Структура проекта

```
├── main.py           # Точка входа: бот + мониторинг + автосинхронизация
├── bot.py            # Telegram Bot хэндлеры (Aiogram 3)
├── parser.py         # Парсер данных АЗС с Яндекс.Карт
├── database.py       # SQLite: пользователи, подписки, снимки АЗС
├── notifier.py       # Уведомления при изменениях топлива
├── keyboards.py      # Клавиатуры и inline-кнопки бота
├── config.py         # Конфигурация (Pydantic v2)
├── web_server.py     # aiohttp-сервер для Mini App
├── index.html        # Фронтенд Mini App
├── style.css         # Стили Mini App
├── app.js            # Логика карты, навигатора и фильтров
├── stations.json     # Автогенерируемый файл с данными АЗС
├── requirements.txt  # Python-зависимости
├── .env              # Секреты (токен бота, ID пользователей)
└── .gitignore        # Исключения Git
```

## 🚀 Запуск

1. Скопировать `.env.example` → `.env` и заполнить:
   ```
   BOT_TOKEN=<токен от @BotFather>
   ADMIN_ID=<ваш Telegram ID>
   ALLOWED_USER_IDS=<через запятую>
   WEBAPP_URL=https://your-domain.github.io/AZS_Volshkiy/
   ```

2. Установить зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Запустить:
   ```bash
   python main.py
   ```

## 🔧 Деплой на Orange Pi

Проект развёрнут на Orange Pi Zero 3 как systemd-сервис `fuel_bot.service`.  
Каждые 3 минуты автоматически коммитит обновлённый `stations.json` в GitHub Pages.
